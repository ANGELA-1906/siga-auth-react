# Módulo de Registro y Autenticación 

Aplicación desarrollada en **React** para el registro de usuarios y validación de credenciales con alertas visuales de éxito y error, enmarcada en el proyecto **SIGA - Milagros Group S.A.S.**

## Credenciales para Validación

* **Contraseña:** `password123`

## Funcionalidades Implementadas
* **Inicio de Sesión (Login):** Valida usuario y contraseña; muestra mensaje verde de éxito si coincide o mensaje rojo de error si los datos son incorrectos.
* **Registro de Usuarios:** Permite crear nuevos usuarios dinámicamente y utilizarlos inmediatamente para iniciar sesión.

## Instalación y Ejecución
1. Instalar dependencias: `npm install`
2. Ejecutar entorno de desarrollo: `npm run dev`
3. Abrir en el navegador la URL indicada en consola (generalmente `http://localhost:5173`).
